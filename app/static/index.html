Spotify listelerini sınırsız ve hızlı şekilde okumak için ücretsiz API anahtarı girin.

Nasıl Alınır? (1 Dakika)

3. Settings sekmesinden Client ID ve Client Secret'ı kopyalayıp buraya yapıştırın.

YouTube Music Bağlantısı

YouTube Music Hesabı
Bağlandı

Hesabınız başarıyla yetkilendirildi. Listeler bu hesaba eklenecektir (Google Cloud kota limiti yoktur).

Google Cloud API kotalarına (66 şarkı limitine) takılmamak için tarayıcı başlıklarıyla limitsiz bağlanın:

Adım Adım Bağlanma Rehberi:
1. Tarayıcınızda music.youtube.com adresini açıp giriş yapın.
2. Klavyeden F12 tuşuna basın ve Network sekmesine gelin.
3. Sayfayı yenileyin. Listeden browse isteğine sağ tıklayın.
4. Copy ➔ Copy request headers deyin ve aşağıya yapıştırın.

Gelişmiş Aktarım ve Eşleştirme Ayarları

IP engeli yememek için her arama arasındaki bekleme (Önerilen: 0.35s).
Şarkı süresi farkı (Yanlış veya 1 saatlik loop versiyonları eler).
Tek seferde listeye yazılan şarkı adedi (Önerilen: 25).
